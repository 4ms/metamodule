# MP2 (A35, AArch64) version of api-keep-list.txt: API symbols to keep that scanning the export
# objects can't find on its own. See api-keep-list.txt for the format.
#
# Differences from MP1:
#   - No data symbols (_impure_ptr, __atexit, ...): an MP2 plugin's libc is the toolchain's
#     (not compiled -fPIC), which can't refer to data in the firmware, so each plugin has its own
#     (see the SDK's cmake/make_plugin_libc_mp2.cmake).
#   - The unwinder (_Unwind_*): plugins use the firmware's, which has their .eh_frame registered
#     (src/mp2-stubs/dynload/exidx_registry.cc). MP1 plugins have their own, and find their exidx
#     tables with mm_host_find_exidx.
#   - The lock functions and C++ exception globals: plugins use the firmware's, which work across
#     the A35's two cores (system/lock_ca35.cc, system/per_core_ca35.cc).
